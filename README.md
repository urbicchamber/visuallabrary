# library

1337 visual references.

[Library](https://director-image-library.mattealbum8.chatgpt.site/) · [GitHub Pages mirror](https://urbicchamber.github.io/visuallabrary/)

Full images in `images/` retain the saved source files. Archive formats unsupported by browsers are converted losslessly, preserving dimensions and pixel values. `thumbs/` contains separate resized previews. `references.json` contains authors, source links and SHA-256 hashes.

Static HTML, CSS and JavaScript. GitHub Pages publishes `main` from the repository root.
