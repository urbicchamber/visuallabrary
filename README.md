# library

1337 visual references and 66 readings on art, interfaces, information and memory.

[Library](https://director-image-library.mattealbum8.chatgpt.site/) · [GitHub Pages mirror](https://urbicchamber.github.io/visuallabrary/)

Full images in `images/` retain the saved source files. Archive formats unsupported by browsers are converted losslessly, preserving dimensions and pixel values. `thumbs/` contains separate resized previews. `references.json` contains authors, source links and SHA-256 hashes.

[Reading collection](https://director-image-library.mattealbum8.chatgpt.site/reading.html) · [Reading mirror](https://urbicchamber.github.io/visuallabrary/reading.html)

`reading-references.json` contains descriptions, short sourced quotations, original quote text, reading links and image credits. Translated quotations are marked. Full texts and excerpts are distinguished. Image and reading favorites use separate browser storage.

Static HTML, CSS and JavaScript. GitHub Pages publishes `main` from the repository root.
